# decod.ing

모르는 글자·깨진 한글·긴 주소·QR 사진을 만난 사람이 형식을 먼저 고르지 않고 기기 안에서 뜻과 주의할 점을 확인하는 무료 도구다. 개발자를 포함한 누구나 대상이며 한국어와 영어를 같은 의미로 제공한다(ADR-005). 형식·도구 수는 `pnpm inventory`가 소유하며 사용 가치나 사용자 수의 증거가 아니다.

첫 여정: 붙여넣기/파일/안전한 예시 → 한 문장 답 → 조심할 점 → 풀린 값과 복사 → 저장·다른 도구·자세한 근거. 입력·결과를 URL·계측·오류 로그로 보내지 않는다. 명시 저장·값 포함은 ADR-006, 즐겨찾기·최근 도구는 기존 ID-only 키를 쓴다. 계정·AI·서버 풀이·유료 구독은 없다.

## 2026-11-16 첫 사용에서 재사용까지

요청 `DECODING-COMPLETE-20261116-OWNER-01`, 피드백 `COMPLETE-FB-FEB64171066A45A8`. 시작 main `21e7e7d`, 운영 runtime `e0afc68`. 실제 브라우저에서 한글 깨짐 복원과 평문의 정직한 비지원 답을 확인했다. 검색 입구 8개는 이미 실제 디코더를 쓴다. 현재 확인한 빈틈은 다음과 같다.

- 즐겨찾기를 13개 이상 써도 읽을 때 12개로 잘라 재방문 시 일부가 사라진다. 별 표시 외에 모아 보는 경로가 없다.
- 최근 도구는 카탈로그 링크 클릭만 기록해 검색 직접 진입이나 결과에서 도구로 간 경로가 빠진다. localStorage 쓰기 예외가 클릭 핸들러 밖으로 나간다.
- 초기화 전 예시 버튼에는 이벤트 핸들러가 없어 아주 이른 클릭이 사라질 수 있다. 이전 원본 회귀 기록에서 초기 클릭 실패가 관측됐다.
- 홈/검색 입구가 서로 직접 연결되지 않아 기존 상황별 설명과 예시를 발견하기 어렵다. 기본으로 풀린 예시와 자신의 입력 결과도 명확히 구분한다.

### 대안과 선택

1. 판별 형식/도구 추가: 실제 미지원 수요가 생기면 재검토한다. 현재의 재방문·첫 클릭 문제를 해결하지 못하므로 이번에는 제외한다.
2. 홈 전체 시각 방향 재설정: 오너가 채택한 A안과 한 문장 답을 유지한다. 이번 증거는 브랜드 전환보다 흐름 연결을 지지한다.
3. **첫 클릭 → 상황별 실제 결과 → 다시 쓰는 도구 연결**: 선택. 기존 의미 owner·저장 키를 재사용하며 비용·데이터·권한·엔진 판정 기준을 넓히지 않는다.

## 비교 근거와 한계

2026-11-16 공식 자료: [CyberChef](https://gchq.github.io/CyberChef/)의 Magic·연산 조합, [DevToys](https://devtoys.app/doc/articles/extension-development/guidelines/UX/support-smart-detection.html)의 도구 추천·전달, [dCode](https://www.dcode.fr/cipher-identifier)의 불확실성 설명. CyberChef 실화면의 동일 Base64 한글 샘플은 입력만으로 출력되지 않았고 Magic을 추가한 뒤 후보 표에 한글이 보였다. 후보 선택/평문 복사는 도구 탐색 timeout으로 확인하지 못했다. 단일 샘플 관찰을 전체 우위나 수요로 일반화하지 않는다. decod.ing은 기존 형식 선택 없는 로컬 풀이를 유지하며 이번에는 재진입 조작과 초기 실패를 줄인다.

## 수익·관측·외부 경계

무료 기능과 `/sponsor/`의 기존 비활성 안전 경로를 유지한다. 광고·판매·외부 연락은 활성화하지 않는다. 자연 검색 유입, 합성/운영자 방문을 분리한 완료 수요, 재방문 신호와 실제 스폰서 수요가 사업 판단 근거이며 현재 모두 미입증이다. 허용된 일곱 집계 이름만 보내고 끌 수 있다.

기존 Worker 웹/PWA 개선·배포만 이번 릴리스 범위다. 실제 휴대폰/화면 낭독/OS 공유, npm 보안 확인·가입·2FA, Chrome 등록·공개, Naver 소유권 및 2026-11-29 이후 J5 관측은 원래 gate를 보존한다. 새 계정·비용·동의·권한·게시·원격 저장은 추정하지 않는다.

## 이번 범위 완료 증거

첫 사용·도구 재사용·기존 안내 연결 세 ID를 웹에서 배포하고 공개본에서 확인했다. 같은 값 재입력의 live 실행과 이전 파일 읽기 취소도 공통 owner에서 고쳤다. [릴리스 영수증](../evidence/completion-2026-10/decoding-return-20261116/release.json)에 고정 소스, provider read-back, 306 단위·114 브라우저 통과/2 대상 외 건너뜀, 실제 공개 과업과 원본 실패 기록을 보존한다. 자연 유입·재방문·수익은 여전히 미입증이다.
