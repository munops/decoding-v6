# decod.ing

모르는 문자열·바이트를 기기 안에서 층별로 해체하고, 위험 경고와 다음 행동을 확인하는 무료 개발자 도구다. 영어가 기본이고 한국어를 색인한다. 계정·AI·값 업로드 없이 47개 기존 도구와 42개 판별기 등록을 유지한다. 이 수는 구현 목록이며 독립 검증의 기능 수나 productPass가 아니다. 전체 기능 수 전후는 unknown/null이며 baseline61에 부분 통과 수를 더하지 않는다.

첫 여정은 홈 입력 또는 합성 예시 → 층 띠 → 선택한 값 복사·값 없는 공유 → 필요하면 구조 저장이다. 여러 줄·비교·수동 해체·JWT 로컬 서명 검증·PNG 파일·다른 도구 전달·백업 복원이 같은 여정에 연결된다. IDB 이름·버전1·기존 지속 기록 형식을 유지하고 탭 기록은 sessionStorage의 가린 구조로 한정한다. 이전 배포로 돌아가도 지속 기록을 읽을 수 있으며 새 버전의 탭 기록은 탭을 닫으면 사라진다.

레이아웃은 흰 바탕·흑연 글자·네 가지 층 색·오프셋 거터와 자체 호스팅 IBM Plex Mono를 사용한다. 390px/1440px 실제 캡처, 최종 clean build, 배포와 라이브 첫 가치는 완료 evidence에서 별도로 기록한다. 현재 코드·단위/정적 검사만으로 화면·배포·가치를 판정하지 않는다.

## 측정과 신뢰

기존 EVENTS 바인딩에 허용된 이벤트 이름만 보낸다. 값·키·파일명·URL·ID·원본 오류는 보내지 않는다. app_open·landing_view·decode_completed·decode_unsupported·return_7d·share_action·sponsor_interest를 첫 화면 푸터에서 끌 수 있다. 첫 방문 날짜는 고정 13개월 뒤 만료되고, 끄면 즉시 지운다. /proof/는 집계도 보내지 않는다. HTTP 수신은 보관·자연 사용 증명이 아니며 7일 재방문과 수익은 미관측이다.

/data/는 읽을 수 있는 설정·탭 항목·가린 기록·캐시를 보고 지우는 곳이다. /privacy/와 /ko/privacy/는 일회성 전달·백업·키 메모리·Cloudflare 요청 처리를 설명한다. 운영자 공개 브랜드만 법적 identity 정본에서 가져오고 개인사업자 PII는 복제하지 않는다.

## 수익과 채널

사용자 도구는 영구 무료다. /sponsor/는 가격 계산식·표시·해지·환불·문의 초안만 제공한다. 캠페인 배열은 비어 있고 결제·광고·판매·외부 연락은 활성화하지 않는다. 독립 PWA 창에는 빈 스폰서 자리도 숨긴다.

웹은 기존 decoding-v6 Worker·decod.ing 무료 표면에만 승인된 guarded 경로로 배포한다. 도메인·DNS·계정·비용·새 자원은 범위 밖이다. Apps in Toss는 계획상 해당 없음이며, 확장·CLI·native 서명 및 스토어 게시도 실행하지 않는다. 실제 Android 공유·iOS 설치·메신저 미리보기·외부 메일 앱·자연 재방문은 기기/외부 관측 대기로 보고한다.
