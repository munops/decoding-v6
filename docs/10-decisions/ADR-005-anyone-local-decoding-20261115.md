# ADR-005: 누구나 쓸 수 있는 로컬 풀이

2026-11-15 · 요청 DECODING-IMPROVE-20261115-OWNER-01 · accepted

대상은 개발자를 포함해 값을 풀어 봐야 하는 누구나다. 인계문의 A안과 README §10의 결정 열다섯 가지를 따른다.
가입·결제·생성형 AI·서버 풀이·광고·주소에 값 싣기는 추가하지 않는다. 횟수 일곱 이름만 세며 끌 수 있다.
이미 구현된 desktop은 별도 승인 전 내놓지 않는다. 확장·CLI 공개는 인계 J7의 계정·이름·권한·비용·순서를 따른다.
화면의 밝은 기본값·일반 글꼴 제목·한국어 우선과 불확실한 결과의 표시 변경은 B/H에서 구현하고 엔진의 0.85/0.15 기준은 유지한다.
