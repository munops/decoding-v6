# ADR-006 — 명시적으로 고른 로컬 값 보관과 건네기

Status: accepted by the2026-11-15 handoff G1/G2 (README settled decision5). Implementation and public release are separate.

기본 저장은 모양만, 기간7일이다. 사용자가 이름·기간(24시간/7일/계속)·값 포함 여부를 고른다. 값 포함은 IndexedDB에만 보관하며 sessionStorage로 옮기지 않는다. 알려진 자격증명 패턴과 비밀 필드 이름은 중앙 엔진 마스커를 통과한다. private-key 판별이 있는 결과는 값을 보관하지 않는다. 중간 인코딩 겹은 값 보관 대상으로 삼지 않고 사용자가 보고 있는 최종 결과만 보관한다. 모든 종류의 비밀을 알아낼 수 있다고 주장하지 않는다.

붙여넣기·디코딩만으로 저장하지 않는다. 값이 든 백업의 내보내기와 복원은 먼저 알리고 확인한다. 백업 입구도 같은 마스커를 통과하며 확인 전 저장소를 변경하지 않는다. 기존 v1 데이터베이스/store와 백업 모양을 유지하고 선택적인 valueMode 필드로 구별한다. rollback 시 이전 구조 전용 importer는 값을 가린다.

건네기는 값 없는 설명을 먼저 권한다. 값을 건넬 때는 비밀 필드를 가리고, 가리지 않기는 별도 확인을 요구한다. 복사·파일·기기 공유는 명시 동작으로만 실행한다. 원문·결과를 링크·텔레메트리·지원 메시지에 자동으로 싣지 않는다. 재현 명령은 받는 사람이 자신의 값을 로컬로 넣는 자리표시자만 담는다.

이는 사용자가 요구한 로컬 보관/내보내기 범위이며, 서버 동기화·계정·외부 입력 조회·데스크톱 공개·추가 provider 권한을 승인하지 않는다. 웹 공개에는 같은 revision의 privacy copy·검증·release wave를 사용한다.
