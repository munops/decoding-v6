대상은 값을 풀어 봐야 하는 누구나입니다. 개발자뿐 아니라 고객 문의를 받는 운영자, 수상한 주소를 받은 보안 담당, 퍼즐 푸는 학생, 깨진 한글 메일을 받은 보통 사람까지. 운영 중인 decod.ing을 처음 온 사람으로 써 보고, 코드를 읽고, 다른 서비스 서른 곳쯤을 살핀 뒤 첫 화면 세 안을 그렸습니다. 아래 휴대폰 틀은 실제로 눌러 볼 수 있고 값이 진짜로 풀립니다.

오너가 정할 것

1. 첫 화면 안 A안A·B·C 가운데 하나.
2. 화면 느낌 밝게밝은 바탕 기본, 제목은 보통 글꼴, 겹 색 넷은 그대로. 어두운 화면은 설정에서.
3. "개발자"를 빼고 "누구나"로 뺀다제목, 검색 설명, 문서.
4. 한국어 브라우저면 한국어 화면부터 그렇게지금은 영어 화면에 안내 띠.
5. 넣어 두기에 "값까지" 넣는다이 기기에만, 직접 고를 때만. 기본은 지금처럼 모양만. 지금 규약은 원문을 어디에도 남기지 않습니다.
6. 주소(링크)에 값을 실어 건네기 안 한다대화방 미리보기와 기록에 남습니다. 대신 다른 앱으로 보내기와 파일.
7. 옛 암호·퍼즐 범위 열쇠 없이 풀리는 것만모스, ROT13·시저 25가지 펼치기, 0과 1.
8. 밖에 물어봐야 되는 일 안 한다짧은 주소 펴기, 위험 주소 조회, 지문 값 원문 찾기. 값이 밖으로 나갑니다.
9. AI로 설명 붙이기 안 한다
10. 확실하지 않을 때 풀어 보여 주고 다른 가능성을 같이지금은 후보 목록에서 멈춥니다.
11. 화면 말 쉬운 말 먼저, 원래 이름은 괄호로그인 토큰(JWT), 지문 값(해시).
12. 광고 계속 끈다
13. 데스크톱 앱·확장 내놓기 웹을 고친 뒤 다시
14. 방문·풀기 횟수와 검색 노출 보기Cloudflare와 Search Console에서 열어 주셔야 볼 수 있습니다.
15. 영어 화면 말 원어민 확인구현은 영어·한국어를 같이 씁니다.

답 없이 바로 할 수 있는 것은 틀린 것 고치기(인계문 묶음 A) 전부입니다.

못 본 것

실화면 조사가 두 번 멈췄습니다. 브라우저 조종권이 오너 쪽에 있었고 다른 도구로 돌려 보지 않았습니다. 도구 여러 개 써 보기, 넣어 두기·건네기 눌러 보기, 정적 지면, 인터넷 끊고 쓰기, 키보드만으로 쓰기, 화면 낭독기는 못 봤습니다. 구현자가 먼저 확인하도록 인계문에 넣었습니다.
  • 방문 수와 검색 노출은 조회 권한이 없어 모릅니다.
  • 진짜 휴대폰이 아니라 폭 390으로 흉내 낸 화면입니다.
  • 다른 서비스가 값을 서버로 보내는지는 정책 글만 봤습니다.
  • 시안 속 풀이는 눌러 보기용 작은 풀이기입니다. 실제 엔진이 아닙니다. 넣어 둔 것 목록과 "2분 14초"는 예시입니다.
